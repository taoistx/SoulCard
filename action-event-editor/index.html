游戏事件文本

                
#槽位ID 定义槽位，[阶段ID] 定义该阶段的规则组，》配方ID 定义组内配方。每级缩进用一个 Tab 或四个空格，阶段正文每行以 | 开头。

                
@event sample
版本：1
标题：菌雾里的金属声
起始阶段：opening
#subject
    名称：菌雾
#field
    名称：周围环境
[opening]
    |你听见远处传来规律的敲击声。
    》observe
        伎俩[focus]》subject
        >你辨出了节奏。

                
配方内每行写一条槽位匹配，同时列出多条时必须全部满足。用 伎俩[!focus]》subject 排除指定卡牌，或用 物品或知识[freshFlesh]》field 匹配资源。配方结果正文以 > 开头，也可用「结果对话」和「结果节点」引用游戏对白。

                
「世界条件」和「世界后果」沿用 JSON 值。@字段 ["字段名", 值] 保留扩展字段。转换后可在「当前 JSON」核对供游戏加载的数据。

              

              

              
DSL v0.1

              
按开场正文、#槽位、》选项 的顺序写。顶层选项顶格写，卡牌规则与所属选项同级。规则的结果缩进一级，@battle 和它的 》胜利 等返回分支同级。每级用一个 Tab 或四个空格。

              
规则用 暴力》粪怪 匹配标签，[肉块]》粪怪 匹配具体卡牌，空》露西 匹配空槽。! 表示否定，& 表示且，| 表示或，按这个顺序运算。圆括号可分组和嵌套，支持全角符号。例如 （执念》露西）|（！暴力》露西）:。

              
同一选项或命名组里的条件从上往下匹配，只执行第一条符合条件的分支。其他: 放在末尾，用于前面的条件都不符合时。正文行以保留符号开头时，在前面加 \。

              
菌雾里传来微弱的敲击声。
#露西 #粪怪
》确认
执念》露西 & 暴力》粪怪:
    @battle monster1?
    》胜利
        +flag: 露西获救
        @exit
    》失败
        @exit
其他:
    这样的行动似乎没有意义。

》离开

              
@jump root 返回面板并清空槽位里的牌。@exit 或单独一行的 》离开 结束本轮。命名规则组 [组ID] 可供 @jump 组ID 跳转，组内规则也顶格写。@battle 带 ? 时进入返回分支，@shop eddie 等待关闭模拟商店。

              
顶层和后续的 》选项 遵循同一套规则。选项可以接下一层的正文和指令，也可以直接接同级的卡牌规则。结果正文和它提供的下一组选项同级，这个结构可以反复嵌套。

              
下一组选项会沿用当前槽位布局，并清空槽位里的牌。重新放牌后点击选项，卡牌规则和 @jump 按这次摆牌匹配。与结果正文同级写 #新槽位 #另一槽位 可替换布局。

              
》确认
执念》露西:
    情况依然危险。
    》继续
    暴力》粪怪:
        @jump options
    其他:
        还需要一张暴力牌。
    》离开
        @exit

[options]
执念》露西 & 暴力》粪怪:
    @battle monster1?
    》胜利
        你击败了粪怪。
    》失败
        你被怪物击倒了。

              
+flag: / -flag: 设置布尔值。+card: / -card: 和 +item: / -item: 每次增减一份。在沙盒配置中注册脚本引用的卡牌、标签、物品、战斗和商店。
