文本语法帮助
直接写正文，第一行也是正文。正文段落间直接留空行即可，转换时自动保留，无需输入反斜杠。同一节点的正文和选项使用相同缩进，选项用》开头区分。选项后的回复才增加一级 Tab 或四个空格；该回复的选项保持同级。节点和选项组 ID 在手动转换时自动分配，左侧目录同时显示两类 ID。统一用 @ID 或 @ ID：引用 node（例如 @root）会进入目标正文、执行目标进入效果；引用 optionList（例如 @mainChoices）保留当前正文，只切换回答组。即使引用 node 前写了正文，也会切换为目标正文；转换会提示。回答下只有 @optionList 时保留当前显示的正文，不重复执行原节点进入效果。ID 不能跨类型重名，不能引用单个 option。不要写 @node、@option 声明。前置（条件1/！（条件2＆条件3））控制显示；末尾（+名称）选择时设置，正文独立一行则进入时设置。-名称设为假。全半角括号、!、&、/ 均支持。正文保留符号可用反斜杠转义。

              
需要调用游戏模块时，在选项的下一行写 #调用ID，并与选项同级缩进。例如在「交易」下一行写 #shop_eddie 来打开商店。
