# v0.6 实施与验收记录

本记录对应当前 Demo 的实现；原稿《腐蚀世界_三天阶段推进_攀高者与空餐桌_v0.6.md》保持不变。原稿中的止血瓶设计按本轮明确要求取消，治疗使用韧膜。

## 已接入内容

- 原地图接出17个节点、18条连接。复用 `start / eddie / node / node3`，新增13个 `slice_*` 节点；保留全部旧节点与事件配置，未参与切片的旧节点没有关联边。父节点探索揭示、双向通行和编辑器继续使用原机制。
- 新局仅带锈剑。物品修订：取肉直接获得鲜肉，食用、交易和诱饵共用此物品；当前资源位置见新版节点报告。鲜肉每份恢复10 HP，满血不可食用，不恢复体力或延长期限。夹道和干台共享一份韧膜。
- 防护实际装备在头槽才抵消菌丛3 HP、回落庭4 HP侵蚀；卸下或献祭头部后失效。破侧廊、扬粉、扶帘和回廊伤害仍生效。单步和自动寻路使用同一跨边函数。
- 回落庭有观察、固定帘、切帘、扶帘、投饵、群战与6 HP硬闯。临时机会在离开或长休后消耗，永久设施与已清理怪群保持。
- 回廊具备警示、入困、脱身、放架、取钩和下层入口。未入困可返回；入困不能长休或关闭面板脱困。另一侧对象在入困时固定，死亡和吊架受困优先于日结迁移。
- 托马斯准备、受伤、治疗分开记录；实际材料、防护或明确路线帮助才计准备。玄一螂预留材料到实际受伤使用时才计治疗。人物在玩家未访问时也随长休演化。
- 艾迪制作、作业位改善、一次鲜肉换当日装备；温妮献祭指引、莫尔旧路线、小皇帝废料搬运（换诱饵交易已取消）、霍兰短互动、玄一螂挑战和死亡掉落已接入。
- 艾迪赠肉节点已删除；其余原节点文本、原选项文本及效果逐项保护，新功能通过追加选项与分支实现。原有“血肉延寿”台词保留，实际食用规则只恢复HP。

## 三条实际路线预算

以下路线从真实新局出发，通过页面操作完成，没有调试赠物、修改日期或补体力。完整身体初始最大HP为66；正常、深探路线自愿献祭眼部后最大HP为60。每天仍为6体力，首次探索仍为1体力，期限仍为5日。

## 维护位置与边界

`world-v06.js` 保存本切片的具名日结、地点入口与行动；`world.js` 提供移动、背包、装备、NPC运行和BattleBridge连接。新对白在 `npc-dialogues/*.json`，行动在 `action-events/slice-*.json`，人物战斗记录在 `battle-data/combatants/*.json`。编辑器通过 `v06Site` 地点入口识别当前切片，可编辑节点、事件集与NPC。

战斗规则与 `game.js` 保持不变。群怪行为在场景结算，未实现动态减怪；皇帝守卫战、霍兰决斗与深层教堂剧情按计划暂缓。边界测试使用真实BattleBridge并确定性结束战斗来检查结果处理，既有卡牌战斗浏览器回归验证实际出牌和装备流程；此验收不代表对所有可选战斗Build的平衡穷举。
